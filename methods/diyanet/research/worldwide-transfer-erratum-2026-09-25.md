# Erratum: frozen Diyanet worldwide transfer plan

The plan fixed three 2027 comparison cities and the existing baseline/candidate before Diyanet prayer-time source access. Its expected UTC-carrier relationship for Auckland was stated as `C=D−1`. The already frozen full forecasts, generated from the listed named-city proxy and timezone, show `C=D` on all 365 dates for **all three** selected cities: Jakarta, Cape Town, and Auckland.

This was a source-free forecast finding, before the first Diyanet calendar search. It is a planning error, not a source-driven correction. We retained all three preselected cities and did not change any model input or candidate. Consequently this cohort tests baseline behavior and no-change controls only; it provides no new data for candidate dates where `C≠D`. Original frozen plan and full forecasts are privately archived.
