# MUIS: public-rule evidence audit

Reviewed 25 September 2026. This was a bounded search of MUIS institutional explanations and a review of the existing reconstruction. No prayer-time API or new calendar rows were requested.

The [MUIS Islamic calendar page](https://www.muis.gov.sg/resources/islamic-calendar/) identifies official annual prayer publications and was marked updated 24 September 2026. The landing page supplies no executable angle, calculation point, ephemeris, margin or rounding specification. A MUIS [speech recalling Syed Isa Semait's manual calculations](https://www.muis.gov.sg/resources/speeches/speech-by-mufti-dr-nazirudin-mohd-nasir-at-syed-isa-semait-scholarship-and-muis-scholarship-award-ceremony--/) confirms the use of astronomical calculation historically, but supplies no numerical recipe.

| Parameter in the current model | Evidence classification after this audit |
|---|---|
| Fajr 20°, Isha 18°, Dhuhr +60 seconds | Secondary software preset evidence, not independently confirmed MUIS production parameters |
| UNGEGN Singapore point | Public geographical proxy, not an identified MUIS calculation station |
| Continuous solar crossings; exact −50′ horizon; ceil all six markers | Our reconstruction; no new institutional confirmation located |
| Ramadan Maghrib +1-minute diagnostic | Archived empirical diagnostic, not a published MUIS rule or default |

Absence from these inspected pages is not proof that MUIS has never published more detail. Generic third-party pages repeating a “MUIS method” label were not used to raise confidence. The complete prescription still needs evidence, particularly for the horizon, source point and differing sunrise/start rounding.

Consequently no formula or geographic contract changes here. The [existing prospective comparison](PROSPECTIVE-2027.md) remains valid under its original scope and limitations. A future unrounded GPS calculation could be an explicitly named hypothesis; it cannot be labelled official MUIS seconds merely because it starts from the same two angles.
